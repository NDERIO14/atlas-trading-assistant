
# ATLAS – AI-Powered Futures Trading Assistant

ATLAS is a web-based AI-powered futures trading research and paper trading platform.

The application analyses historical market data, calculates technical indicators, identifies market regimes using machine learning, generates trading signals, and allows users to simulate trades using virtual capital.

## Project Objectives

- Analyse historical futures market data.
- Calculate technical indicators.
- Classify market conditions using machine learning.
- Generate BUY, SELL, and HOLD signals.
- Calculate trading risk and position size.
- Simulate trades using a virtual portfolio.
- Backtest trading strategies.
- Analyse trading performance.
